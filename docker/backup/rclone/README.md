# Configuration rclone (copie hors site, facultative)

Placez ici un `rclone.conf` (jamais versionné) ou indiquez un autre dossier avec `RCLONE_CONFIG_DIR`,
puis renseignez `RCLONE_REMOTE` dans `.env` (ex. `b2:modulis-sauvegardes` ou `gdrive:Modulis/sauvegardes`).
Voir docs/SAUVEGARDES.md, section « Copie hors site ».
